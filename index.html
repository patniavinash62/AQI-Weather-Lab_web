01 · Data & missing values

Missing time-series data, handled carefully

Sensors go offline for days. Filling blindly would invent data and distort correlations, so every analysis pairs values by calendar date, never by row position, and you control the gap policy.

AQI recordedMissing (sensor outage)
Rules used: (1) missing ≠ 0, so it is stored as NULL/NaN; (2) pairwise-complete observations for correlations; (3) only short gaps (≤3 days) are linearly interpolated, and never for rainfall, since interpolating would invent rain; (4) lag features are built by date arithmetic, so a lag never silently jumps across an outage.

04 · Correlation analysis

Correlation matrix: pollutants × weather

Click any cell to inspect the scatter plot. Switch between Pearson (linear), Spearman (monotonic, rank-based), and their absolute difference.

Correlation matrix

Pair

Correlation ≠ causation. Temperature and AQI are strongly negatively correlated in the raw data, but cold weather doesn't "make" smog on its own. Winter brings low mixing heights, crop burning, heating and festivals together. Tick Remove seasonality and watch the correlation shrink: season was a confounder. Even then, an association is not proof of a mechanism; only physical reasoning, natural experiments (e.g. the 2020 lockdown) or controlled models can support causal claims.
05 · Theory vs experiment

When Pearson and Spearman disagree

Pearson measures linear association using raw values, so a few extreme points can dominate it. Spearman is Pearson computed on ranks, so it is robust to outliers and captures any monotonic curve.

06 · Hypothesis testing

Does AQI differ between cities or seasons?

H₀: all groups share the same mean (ANOVA) or the same distribution (Kruskal–Wallis). AQI is right-skewed with unequal group variances, so the rank-based test is the safer one.
